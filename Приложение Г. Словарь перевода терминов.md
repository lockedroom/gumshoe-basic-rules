# Приложение Г. Словарь перевода терминов

## Ключевые термины

- GUMSHOE → СЫЩИК
- Investigator → сыщик
- GM, Keeper, Director → ведущий
- Investigative Ability → исследовательская способность
	- Academic Ability → научная способность
	- Technical Ability → прикладная способность
	- Interpersonal Ability → межличностная способность
- General Ability → общая способность
- (ability) point → пункт (способности)
- (ability) pool → запас (способности)
- (ability) rating → рейтинг (способности)
- point spend → трата пункта

## Создание персонажа

- Concept → концепция персонажа
- Occupation → род занятий
- Drive → мотив
- Credit Rating → статус

- Foreign Languages → иностранные языки
- Forensic Psychology → криминальная психология
- Forensic Anthropology → судмедэкспертиза
- High Society → высшее общество
- History → история

- First Aid → первая помощь

- Infiltration → проникновение

- Scuffling → драка
- Sense Trouble → бдительность
- Shooting → стрельба

## Проверки и состязания

- Test → проверка
- Simple Tests → простые проверки
- Difficulty → сложность
- Margin → степень успеха/степень провала
- Alertness modifier → модификатор бдительности
- Stealth modifier → модификатор скрытности
- Surprise → застать врасплох
- Retries → повторные проверки
- Piggybacking → помощь команде
- Cooperation → помощь лидеру
- Continuing Challenges → продолжительные испытания
- General Spends → необходимые траты
- Contests → состязания
- Blind Contests → закрытые состязания
- Quick Contests → быстрые состязания

## Сражения

- Round → раунд
- Turn → ход
- Damage → урон
- Damage Modifier → модификатор урона
- Non-Lethal Damage → нелетальный урон
- Hit Threshold → защита
- Range → дистанция
	- Point-Blank → в упор
	- Close → ближняя
	- Near → средняя
	- Long → дальняя
- Armor → броня
- Cover → укрытие
- Ammo Capacity → запас патронов
- Automatic Fire → автоматический огонь
- Explosive Class → класс взрыва
- Explosive Range → зона взрыва
	- Annihilation range → зона уничтожения
	- Damage range → зона поражения
	- Debris range → зона осколков
- Running Away → бегство из боя

## Ранения и урон

- Consciousness Test → проверка на потерю сознания
- Exhaustion → усталость
- Hurt → лёгкое ранение
- Seriously Wounded → тяжёлое ранение
- Death → смерть

## Самообладание и безумие

- Stability, Composure → самообладание
- Shrink → психотерапия
- Source Of Stability → фактор самообладания
- Shaken → шок
- Shattered, Blasted → надлом
- Gone, Doomed → безумие
- Hard/Soft driver → жёсткая/мягкая мотивация

## Улики и их поиск

- Clue → улика
- Core Clues → ключевые улики
- Non-Core Clues, Extra Clues → дополнительные улики
- Leveraged clues → обусловленные улики
- Pipe clues → связующие улики
- Inconspicuous Clues → пассивное обнаружение улик
- Simple Search → простой поиск
- (Special) Benefits → особые преимущества
- Dedicated Pool Points → целевые пункты

## Дополнительные и альтернативные правила

- «…And stay down!» → «…и не вставай!»
- Trading Points → обмен пунктами
- Mastery → мастерство
- Cherry → козырь
- Push → усилие
- Stun rating → рейтинг оглушения
- Stun test → проверка на оглушение
